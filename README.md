# Space Bounty Hunters

REST API for a space bounty hunters guild: wanted criminals database + hunt journal.

Stack (same as project work): **Django + Django REST Framework + PostgreSQL**, Docker Compose.

## Quick start

```bash
cp .env.example .env
docker compose up --build
```

API base: http://localhost:8000/api/

On startup the backend runs migrations and seeds **6 criminals** and **12 hunt logs** (idempotent).

## Models

### WantedCriminal
`id`, `name` (nullable), `nickname`, `reward`, `latitude`/`longitude` (optional), `location_note`, `difficulty` (1–10), `armed`, `has_crew`, `escape_master`

### HuntLog
`id`, `criminal` (FK → WantedCriminal, one-to-many), `success`, `notes`, `created_at` (auto, server-side)

## API

### Criminals
| Method | URL | Description |
|--------|-----|-------------|
| GET | `/api/criminals/` | List criminals |
| GET | `/api/criminals/{id}/` | Criminal details |

Query params (combinable): `min_reward`, `max_reward`, `armed`, `has_crew`, `escape_master`, `sort=reward` or `sort=-reward`

Example: `/api/criminals/?min_reward=5000&armed=true&sort=-reward`

### Hunts (full CRUD)
| Method | URL | Description |
|--------|-----|-------------|
| GET | `/api/hunts/` | List hunt logs (`?criminal_id=` filter) |
| GET | `/api/hunts/{id}/` | One hunt log |
| POST | `/api/hunts/` | Create capture attempt |
| PATCH | `/api/hunts/{id}/` | Update success/notes |
| DELETE | `/api/hunts/{id}/` | Delete hunt log |

Example POST:

```json
{
  "criminal_id": 3,
  "success": false,
  "notes": "Target escaped through an asteroid field."
}
```

`created_at` is generated by the server. Invalid `criminal_id` → `400`. Missing id → `404`.

## Postman

Import `postman/Space_Bounty_Hunters_API.postman_collection.json`.

## Database setup / import

1. Copy `.env.example` → `.env` and set passwords.
2. `docker compose up --build` — Postgres starts, migrations apply, `seed_data` fills sample rows.
3. Persistent data: named volume `pgdata`.
4. To re-seed from scratch: `docker compose down -v` then `docker compose up --build`.

Manual seed (inside backend container):

```bash
docker compose exec backend python manage.py seed_data
```
